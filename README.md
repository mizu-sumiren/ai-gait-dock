# AI歩行ドック

スマホで撮った歩行動画から、歩き方を数値で記録し、前回からの変化を確認するためのアプリです。
診断やリスク判定を行うものではありません。

## 出る指標

| 指標 | 撮り方 | 位置づけ |
|---|---|---|
| 歩行速度（距離÷時間を手入力） | 正面・側面 | 転倒予防 |
| 歩行率、ストライド時間 | 正面・側面 | 転倒予防 |
| ストライド時間のばらつき (CV) | 正面（2〜3往復）がおすすめ | 転倒予防 |
| 体幹の前傾 | 側面 | 参考値 |
| 立脚中期の膝の曲がり | 側面 | 参考値 |

結果はCSVで保存でき、次回そのCSVを読み込むと前回との差が表示されます。

## 構成

- `app.py` … 画面（Streamlit）
- `gait/pose.py` … 動画から骨格を取り出す（MediaPipe）
- `gait/analysis.py` … 指標の計算（画面に依存しない）
- `gait/reference.py` … 画面に出す目安と出典
- `tests/` … 答えの分かっている人工データでのテスト（`python -m pytest`）

## まだ確かめられていないこと

- 実際の動画での精度（とくに正面からの歩のタイミング検出）。ストップウォッチや歩数の手計測と比べて確認してください。
- 方向転換の自動除外は、肩幅の見え方を使った簡易的な方法です。
